# Agent instructions

Before any design, implementation, testing, review, or documentation change in this repository, read [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) in full. It is the single development context and local source of truth for design facts.

When implementation, verified source-code facts, or user decisions change its contents, update `docs/DEVELOPMENT.md` in the same change; do not create a second design, RFC, baseline, or context document.
